# Клиппинг

Режем длинное видео на вертикальные клипы 1080×1920 с хуком и субтитрами по словам.

## Новая кампания

1. Скопировать `clipping\_шаблон` в `clipping\<название>` и заполнить `brief.md`
   (строки `Автор:` и `Хештеги:` попадают в подписи).
2. Запустить по порядку из корня проекта (PowerShell):

```
.\.venv\Scripts\Activate.ps1
$env:PYTHONUTF8 = "1"

python tools\clipping\download.py   clipping\<название> <ссылка на YouTube>
python tools\clipping\transcribe.py clipping\<название>
# читаем source\transcript.txt, выбираем моменты, пишем clips.json
python tools\clipping\cut.py        clipping\<название>
python tools\clipping\words.py      clipping\<название>
python tools\clipping\render.py     clipping\<название>
python tools\clipping\publish.py    clipping\<название> "Клиппинг — <Автор>"
```

`cut.py`, `words.py`, `render.py` принимают номер клипа в конце: `render.py clipping\<название> 7`.

Если видео уже скачано, положите его в `clipping\<название>\source\` и пропустите `download.py`.

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `source\` | исходник, `transcript.txt` (секунды в квадратных скобках идут в `parts`) |
| `clips.json` | список клипов: `n`, `hook`, `parts`, необязательная `caption` |
| `work\cNN\` | временное: нарезка, слова, субтитры |
| `out\` | готовые клипы |
| `publish\`, `подписи.txt` | клипы с понятными именами и тексты для TikTok |

## Важно

- Один тяжёлый процесс за раз: транскрибация + браузер + ffmpeg вместе вешают ПК на 8 ГБ.
- `cut.py` предупреждает, если клип вне 20–70 секунд или заходит в последние 15% выпуска (финал).
- Язык речи задаётся строкой `Язык: en` в `brief.md` (по умолчанию русский).
- Убрать вебкамеру автора из кадра: поле `"crop_x": 400` у клипа в `clips.json` сдвигает окно вправо
  (число — отступ слева в пикселях кадра высотой 880). Сцены, где автор на весь экран, вырезаются через `parts`.
- Настройки под себя: язык по умолчанию — `LANGUAGE` в `common.py`; мат, раскладка кадра (`VF`), положение субтитров — в `render.py`.
