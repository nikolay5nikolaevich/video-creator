# Style intake — как выбрать стиль на Phase 3 (сам, без опроса)

**По умолчанию скилл не спрашивает пользователя.** Ты выбираешь стиль серии сам, а этот файл — справочник хороших дефолтов и готовых токенов. Три решения, которые надо принять:
- базовый slug серии,
- палитра/настроение,
- шрифт-акцент.

**Длительность** считается per-бролл из количества слов (см. «Pacing» в SKILL.md). **Сколько броллов** — известно из таблицы. Ничего из этого не выбирается вручную.

Спрашивать (через `AskUserQuestion` по шаблону ниже) допустимо **только если пользователь явно попросил дать ему выбрать стиль/палитру/slug**. В обычном автономном прогоне — не спрашивай, реши сам и озвучь выбор одной строкой.

## Как выбрать (эвристики)

- **Палитра** — по теме и тону ролика:
  - про разработку / ИИ / Claude / MCP / технические темы → «Dark + indigo glow» или «Чёрный + Anthropic terracotta» (terracotta — сильный узнаваемый бренд-акцент для Claude-контента);
  - продуктовые / лайфстайл / обучающие → «Светлый минимализм»;
  - хайповые / резкие / молодёжные → «Неон/streetwear».
  Бери ту, что сам считаешь наилучшей для этой серии; при равных — тёмная тех-палитра как безопасный дефолт.
- **Шрифт** — `system-ui` по умолчанию (без новых зависимостей). Кастомный (Inter / JetBrains Mono) — только если `@remotion/google-fonts` уже установлен и он явно усиливает стиль.
- **Slug** — авто из заголовка страницы / шапки (см. ниже).

## Авто-предложение базового slug

- Сначала смотри заголовок Notion-страницы — обычно это краткое описание ролика («Как использовать Claude Code бесплатно» → `claude-code-free`).
- Если в первой ячейке шапки таблицы есть ссылка на референсный рилз — можно взять `instagram.com/reel/<ID>/ • описание` → транслитерировать описание.
- Транслитерация: русский → lowercase ASCII (`утренняя рутина` → `morning-routine`).
- Проверь, что слаг свободен — `ls src/animations/` и убедись, что нет существующих папок с префиксом `<slug>-`.

Базовый slug — это **префикс** для серии. Финальные имена композиций будут вида `<base>-01-full`, `<base>-02-half`, и т.д.

## Маппинг ответов на design tokens

Эти дефолты применяй при генерации всех броллов серии, если пользователь не уточнил иное.

### Палитра

| Палитра | Background | Primary text | Accent | Glow |
|---|---|---|---|---|
| Dark + indigo glow | `radial-gradient(circle at 50% 0%, #1e1b4b 0%, #0b1026 55%, #050816 100%)` | `#fff` | `#a5b4fc` | `rgba(129,140,248,0.5)` |
| Чёрный + Anthropic terracotta | `#000` (плоский) или `radial-gradient(circle at 50% 30%, #1a0f0a 0%, #000 70%)` | `#fff` | `#cc785c` (terracotta), вторичный `#fed7aa` | `rgba(204,120,92,0.4)` |
| Светлый минимализм | `#fafaf7` | `#0f172a` | `#0f172a` (чёрный акцент) | none |
| Неон/streetwear | `#000` | `#fff` | `#a3ff00` (lime) или `#ff2e9a` (magenta) | accent at 0.6 alpha |

### Шрифт

| Выбор | font-family CSS |
|---|---|
| system-ui | `system-ui, -apple-system, sans-serif` |
| Sans-serif гротеск (Inter) | `'Inter', system-ui, sans-serif` (нужен `@remotion/google-fonts` в `package.json`) |
| Monospace для кода + system-ui | `'JetBrains Mono', Menlo, monospace` для код-сцен, `system-ui, ...` для текстовых |

Если `@remotion/google-fonts` **не установлен** — упомяни это пользователю и используй системный fallback, чтобы не вводить новую зависимость без согласия.

## Half-top адаптация палитры

Для броллов с mode `half-top` (канвас 1080×1920, графика только в top `[0, 960]`) используется та же палитра, но **без глубокого затемнения снизу**:

- Dark + indigo glow → плоский тёмный фон без bottom-glow (низ — это переход к лицу ведущего, лишний контраст там вредит).
- Анти-паттерн: радиальный gradient с центром в `50% 100%` (он создаст светлое пятно ровно на стыке с лицом).
- Если по дизайну хочется зон-разделитель — тонкая accent-линия `height: 2–3px` снизу композиции, цветом accent.
