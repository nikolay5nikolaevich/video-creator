# Видео

Короткие вертикальные ролики (9:16, 1080×1920). Три независимых проекта с разными стеками. Общего кода и общих настроек у них нет.

| Папка | Что делает | Стек |
|---|---|---|
| `монтаж/` | монтаж рилзов, моушн-графика по сценарию из Notion | Remotion, Node, Notion |
| `нарезка/` | нарезка длинных видео на клипы с субтитрами | Python, whisper, ffmpeg |
| `анимация/` | анимация в Roblox Studio, покадровый рендер | Python, ffmpeg, Roblox Studio |
| `общее/` | то, что нужно двум и более проектам | — |

## Как работать

- **Открывайте в VS Code подпапку проекта, а не `видео/`.** Так подхватываются только его `CLAUDE.md`, `.claude/` и `.mcp.json`. Notion и скиллы монтажа не должны попадать в анимацию и нарезку.
- У каждого проекта свои `CLAUDE.md`, `.claude/`, зависимости (`node_modules`, `.venv`). Подробности смотрите в `CLAUDE.md` проекта.
- Notion, MCP-серверы и скиллы лежат только в том проекте, которому они нужны.
- Файл переезжает в `общее/`, когда он понадобился второму проекту, а не заранее.

## Границы между проектами

- **В каждой папке свои правила.** Работая в проекте, следуйте его `CLAUDE.md`. Правила, скиллы и привычки соседнего проекта на него не распространяются.
- **Не тяните ничего из соседних папок.** Не импортируйте чужой код, не ссылайтесь на чужие файлы по пути `../другой-проект/`, не копируйте чужие скиллы, MCP-серверы и зависимости.
- Если задача касается одного проекта, читайте и меняйте только его папку.
- Понадобилось то же самое во втором проекте — перенесите файл в `общее/` и подключайте оттуда.

## Что установить

Общее для всех трёх проектов:

- **Git**
- **ffmpeg** в PATH (полная сборка, вместе с `ffprobe`)

По проектам:

| Проект | Что нужно | Установка |
|---|---|---|
| `монтаж/` | Node.js 24, ключ Notion | `npm install` в `монтаж/` и в `монтаж/tools/notion-comment-files/`; `NOTION_API_KEY` в `монтаж/.env` |
| `нарезка/` | Python 3.12 | `python -m venv .venv`, затем `pip install faster-whisper yt-dlp numpy`; модель whisper `small` скачается сама при первой транскрибации |
| `анимация/` | Python 3.12, Roblox Studio, Blender (для роликов на `bpy`) | `pip install pillow numpy` |

В репозитории лежат только код и тексты. Видео, кадры, ассеты, модель whisper, `node_modules`, `.venv` и `.env` в git не попадают (см. `.gitignore`), их нужно скачать или собрать заново.

## Общее для всех роликов

- Формат 1080×1920, ролики для Shorts/TikTok/Reels.
- ffmpeg должен быть в PATH.
