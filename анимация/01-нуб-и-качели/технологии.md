# Технологии ролика «Нуб и качели»

Ролик снят внутри Roblox Studio: сцена и анимация написаны кодом на Luau, кадры сняты с окна Studio по одному, звук собран на Python. Запись экрана и ручной монтаж не использовались.

## Коротко

| Задача | Чем сделано | Файл |
|---|---|---|
| 3D-сцена, анимация, камера, эффекты | Roblox Studio, скрипт на Luau | `Film.luau` |
| Персонажи, позы, лица | модуль `Rig` в Studio (`ReplicatedStorage.Rig`) | на диске копии нет |
| Облачка с эмодзи | `BillboardGui` в Studio | `Film.luau` |
| Покадровый захват | Python 3.12, Pillow, Win32 `PrintWindow` через ctypes, локальный HTTP-сервер | `../capture.py` |
| Звук | Python 3.12 и numpy, готовый музыкальный трек | `sfx.py` |
| Обрезка, поворот, сборка mp4 | ffmpeg 9.0.1 | `../build.sh` |

## Картинка

**Roblox Studio.** Всё, что видно в кадре, рендерит движок Roblox. `Film.build()` собирает сцену из стандартных деталей (`Part`: блоки, шары, цилиндры): поле с деревьями и домиком, качели, чёрный короб космоса с 240 звёздами, Луну с кратерами, Землю. Готовых моделей и текстур из каталога нет, материалы встроенные (`SmoothPlastic`, `WoodPlanks`, `Neon`).

- **Персонажи** — четыре блочных рига (Нуб, Про, Качок, Пришелец) из модуля `Rig`. Поза задаётся углами торса, головы, рук и ног, плюс растяжение тела (`stretch`) для сплющивания при ударах.
- **Лица** задаются набором чисел: размер глаз, положение зрачков, наклон бровей, форма рта. Между двумя лицами возможен плавный переход. Как именно `Rig` их рисует, по файлам на диске не видно.
- **Реплики** — белые облачка с эмодзи над головой (`BillboardGui`), повёрнутые на 90°, потому что камера лежит набок.
- **Эффекты** сделаны деталями, а не системой частиц: пыль, огонь, дым, штрихи звёзд — это шары и бруски, которым на каждом кадре выставляются позиция, размер и прозрачность. Вспышки при ударах — `ColorCorrectionEffect`, дымка — `Atmosphere`.

**Анимация как функция времени.** Физика движка не используется. `Film.apply(S, t)` для любого момента выставляет доску качелей, позы, лица, облачка, эффекты и возвращает положение камеры. Траектории полётов и затухающие колебания после ударов посчитаны формулами. В камеру встроены 20 с лишним планов и тряска при ударах.

**Захват кадров.** Кадр в реальном времени не записывается. Скрипт в Studio выставляет сцену на момент `t` и запрашивает `http://127.0.0.1:8791/shot?n=<номер>`. `capture.py` снимает окно Studio функцией `PrintWindow` и сохраняет PNG. Сам цикл рендера на диске не сохранён, он запускался в Studio.

**Разрешение не родное.** Вертикальный кадр снимается в горизонтальном вьюпорте повёрнутой набок камерой. `build.sh` вырезает область 1525×858, поворачивает её и растягивает до 1080×1920. Исходный кадр — 858×1525, то есть картинка увеличена примерно в 1,26 раза. Размытия в движении и глубины резкости нет.

## Звук

`sfx.py` сводит дорожку из трёх слоёв:

- **Музыка** — Kevin MacLeod, «Pixel Peeker Polka (faster)», лицензия CC BY 4.0. ffmpeg вырезает 24,8 секунды трека; второй вариант того же фрагмента пропущен через фильтр низких частот и звучит в сценах космоса и Луны.
- **Синтез эффектов** на чистом Python: шаги, удары, «боинг», свист, звоночек. Эффекты настроены на ноты трека (до, ре, фа, соль).
- **«Голоса» персонажей** — короткие ноты по сетке восьмых долей музыки, у каждого героя свой регистр.

Музыка автоматически приглушается под голосами и ударами и замолкает перед главными ударами. Сведение — numpy, итог 44,1 кГц стерео.

Тайминги записаны дважды: в `Film.luau` и в `sfx.py`. При сдвиге сцены правятся оба файла.

## Сборка

`build.sh` через ffmpeg собирает 1488 кадров и звук в mp4: H.264 (CRF 16), 1080×1920, 60 кадров/с, звук AAC 192 кбит/с. Длительность 24,8 секунды. Кадры занимают 1,2 ГБ.

В `готовое/` лежат два варианта: `нуб_и_качели_polka.mp4` и `нуб_и_качели_с_музыкой.mp4`. Текущий `sfx.py` собирает вариант с полькой.

## Чем этот способ ограничен

- Нужен запущенный Roblox Studio с окном строго заданного размера (1924×1055). Изменились окно или панели — обрезку надо пересчитывать через `/calibrate`.
- Работает только в Windows: захват идёт через Win32.
- Модуль `Rig` существует только в файле места Studio. Без него `Film.luau` не запустится, а в git его нет.
- Картинка увеличена из 858×1525, мелкие детали мягче, чем при родном рендере.

## Что нужно на новой машине

1. Roblox Studio и место, в котором лежит `ReplicatedStorage.Rig`.
2. Python 3.12 с пакетами `pillow` и `numpy`.
3. ffmpeg в PATH.
4. Трек `../аудио/фоновая-музыка/31-Pixel Peeker Polka (faster)/трек.mp3` (в git не попадает).

`концепт.md` описывает раннюю версию на 14 секунд с паровозом. Готовый ролик длиннее и идёт по другому сюжету; источник правды — `Film.luau`.
